# Data access and privacy

This dashboard visualises results produced by a companion research pipeline,
[german-gdp-nowcasting](https://github.com/Nikta-Kiani/german-gdp-nowcasting),
whose source workbook combines ifo and Macrobond series with official German
and European macroeconomic releases. Those data may be subject to
institutional or commercial redistribution restrictions, and — consistent
with that pipeline's own [`docs/DATA.md`](https://github.com/Nikta-Kiani/german-gdp-nowcasting/blob/main/docs/DATA.md) —
derived panels, metadata exports, and model outputs are **not distributed
in this public repository** for the same reason.

## What ships in this repo instead

`data/demo/` contains a **synthetic sample dataset**: fabricated series ids,
fabricated GDP growth, fabricated model errors — generated by
[`scripts/generate_demo_data.py`](../scripts/generate_demo_data.py) from a
seeded random-number generator. It exists purely so the app has *something*
schema-correct to render on a clean clone. Treat every number in demo mode as
illustrative only (the dashboard shows a "Demo mode" banner whenever it is
active).

## Viewing the real results

The real analysis is deployed separately, with real outputs kept out of any
public repository — see the **Live demo** link in the main
[README](../README.md). If you have your own copy of the real output
artefacts, drop them into `data/real/` (gitignored) or point
`DASHBOARD_DATA_DIR` at their location; see [`data/README.md`](../data/README.md)
for the exact expected layout.

## Reproducing the underlying research

The nowcasting and indicator-selection pipeline that produces these results
lives in a separate repository:
[german-gdp-nowcasting](https://github.com/Nikta-Kiani/german-gdp-nowcasting).
That repo documents how to configure private data paths and reproduce the
full pipeline from the licensed source workbook.
