# Data access

This dashboard visualises results from the companion pipeline
[german-gdp-nowcasting](https://github.com/Nikta-Kiani/german-gdp-nowcasting).
The source workbook mixes ifo and Macrobond series with official German and
European releases. Those data may be subject to redistribution restrictions,
so derived panels, metadata and model outputs are **not** in this public
repository.

## What ships here instead

`data/demo/` is a synthetic sample: fabricated series ids, fabricated GDP
growth, fabricated model errors. It is generated by
[`scripts/generate_demo_data.py`](../scripts/generate_demo_data.py) from a
seeded random-number generator, with the same file layout the app expects.
Treat every number in demo mode as illustrative. The sidebar shows a
"Demo mode" banner whenever that sample is in use.

## Viewing the real results

The analysis is deployed at
**<https://german-gdp-nowcast-dashboard.streamlit.app>**.

That app fills `data/real/` at startup from a separate, private, data-only
GitHub repository, using a fine-grained read-only token stored in Streamlit
secrets (see [`src/dashboard/bootstrap.py`](../src/dashboard/bootstrap.py)).
Neither the real files nor the token enter this codebase or its git history.

If you already have the pipeline outputs, stage them locally:

```bash
python scripts/stage_real_data.py --source /path/to/german-gdp-nowcasting
```

or set `DASHBOARD_DATA_DIR`. The expected layout is in
[`data/README.md`](../data/README.md).

## Reproducing the estimates

The selection and nowcasting pipeline lives in
[german-gdp-nowcasting](https://github.com/Nikta-Kiani/german-gdp-nowcasting).
That repository documents how to configure private data paths and rerun the
full exercise from the licensed workbook.
